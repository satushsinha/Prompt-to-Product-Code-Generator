# Agentic Codebase Generator 🚀

An end-to-end **agentic workflow** built with **LangGraph** that generates **production-ready project codebases** automatically. The system uses coordinated agents for requirement parsing, architecture planning, and code synthesis—dramatically reducing software bootstrapping time.

---

## 🔗 Features
- **Requirement Parsing Agent** – Extracts specs, constraints, and tech stack  
- **Architecture Planning Agent** – Designs folder structure & component layout  
- **Code Synthesis Agent** – Generates source code, configs, and docs  
- **Structured Output** – Clean project hierarchy + auto-generated README

## 🧩 Tech
- LangGraph  
- OpenAI / Local LLMs  
- Python
